# V2.0.1 分类颜色修复

本次只调整颜色分配、对应测试及测试安装包标识，沿用原 V2 功能。

- 移除分类名称哈希到8色的循环分配。
- 使用感知色彩空间中的最大最小距离选色，优先拉开新增类别与已有类别的视觉差异；候选池用完后继续分配未使用的 RGB 颜色。
- 自动修复原有重复颜色（忽略十六进制大小写），保留每种颜色的首个所有者与其他独立颜色；修复前的映射保存在 categoryColorsBeforeUniqueV1。
- 活跃分类、历史分类及删除后保留的映射一起预留颜色，刷新、切换主题或排序不重新洗牌。不会修改任何计时记录、分类名称或复盘内容。
- 首页、图表、明细、图例和原生悬浮窗共享同一持久化映射。新分配的颜色与标签深色文字的对比度至少4.5:1。
- 有限屏幕上项目数量很大时，颜色可能逐渐接近；保证不重复不等于无限数量的颜色都能凭肉眼轻松区分。

验证新增：128个连续新增分类互不重复且不改动已有颜色；1000分类候选池耗尽测试；重复色迁移、预留与重加、刷新、特殊名称、首8色差异；浏览器实际新增第9个项目，并核对首页、饼图像素、统计条与明细；Java验证原生悬浮窗读取同一颜色映射。完整回归结果和实际APK链接以PR最新成功构建为准。
